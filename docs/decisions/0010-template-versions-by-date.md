# 0010. 양식의 판은 템플릿을 따로 두고 날짜로 가린다

상태: 채택 (2026-10). 작업 지시서 [tasks/0002](../tasks/0002-full-archive-and-evalset.md) 4.4.
보완 → [0018](0018-concurrent-variants.md): 같은 날 섞여 쓰이는 판은 두 판 모두 `concurrent: true` 면 기간이 겹쳐도 되고, 괘선 오차로 고른다.

## 상황

약 150일치 묶음 사이에 양식이 개정됐을 수 있다. 특히 편×차량 행렬은 열 머리글에 운전자·차량번호가 인쇄되어 있어(ADR 0004)
사람이나 차가 바뀌면 양식을 다시 찍는다. 개정판끼리는 머리글 몇 글자만 다르다.

## 결정

1. **개정판은 이름이 다른 템플릿이다.** 선택 항목 `family`(계열), `valid_from`, `valid_to`(날짜, 양 끝 포함)를 둔다.
2. **쪽의 날짜를 알면 그날 유효한 템플릿만 분류 후보로 삼는다** (`forms/sitepack.templates_for`, `forms/classify.classify(candidates=…)`).
   유효 기간이 없는 템플릿은 언제나 후보다. 날짜를 모르는 쪽은 전체가 후보다.
3. **같은 계열 안에서 유효 기간이 겹치면 사이트 팩을 읽을 때 오류다.**

## 이유

- 모양으로는 가릴 수 없다. 두 판의 ORB 정합 인라이어가 거의 같아 분류 여유가 1 에 가깝다 (테스트 `test_without_dates_the_two_versions_are_indistinguishable` 이 보여 준다).
  날짜로는 틀림없이 가려진다.
- 머리글이 맞아야 배차 관측(`eq_assignment_obs`)의 "인쇄된 머리글과 다름"이 맞고, 자리(slot) 해석이 맞는다.
- 템플릿을 따로 두면 기준 이미지·좌표가 판마다 독립이라 괘선이 조금 움직인 개정도 같은 방식으로 다룬다.

## 버린 것

- 한 템플릿에 머리글 값만 날짜별로 두는 방식 — 머리글 외에 괘선·문구가 바뀐 개정을 다룰 수 없고, 분류와 정합이 같은 기준 이미지를 쓰는 전제가 깨진다.

## 대가

- 개정판마다 기준 이미지를 다시 떠야 한다 (절차는 `docs/SITE_PACK.md`).
- 날짜가 틀린 파일(파일명 규칙이 어긋난 경우)은 틀린 판으로 분류될 수 있다. `report --by-month` 의 정합 수치로 드러난다.
