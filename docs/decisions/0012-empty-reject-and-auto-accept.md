# 0012. 숫자 인식기의 답은 셋(숫자열·빈 칸·거절), 자동 적재 기준은 검증 날짜에서

상태: 채택 (2026-10). 작업 지시서 [tasks/0003](../tasks/0003-digit-recognizer.md) 4.3, 4.4, 4.6.

## 상황

실제 운반 칸에서 잉크로 "값 있음"이라고 판정된 칸의 약 5분의 1은 이 칸의 숫자가 아니었다: X 표, 덧칠해 지운 것, 윗칸 숫자의 아랫부분,
칸 위에 걸쳐 쓴 메모. 숫자만 읽는 인식기는 이런 칸에도 숫자를 지어낸다. 반대로 숫자처럼 보이지만 사람도 못 읽는 칸이 있다.
자동 적재가 늘수록 사람이 덜 보지만, 자동 적재된 값의 오류는 아무도 보지 않는다.

## 결정

1. **답은 셋이다**: 숫자열(앞의 0 을 뗀 십진수 — 검수가 저장하는 형태), 빈 칸(`""`, 잉크는 있지만 이 칸의 값이 아니다),
   거절(`"?"`, 검수의 `illegible` 로 학습한다). 출력은 CTC — 자릿수를 고정하지 않고, 값 전체를 분류 항목으로 두지 않는다.
2. **신뢰도는 그 답의 확률**(같은 답으로 접히는 경로의 합 — 빔 탐색, `"07"` 과 `"7"` 은 합친다)이고 검증 날짜에서 온도 하나로 보정한다.
   후보는 상위 5개를 남긴다.
3. **자동 적재 표** (`handlers/base.number_status`, 기준 t):

   | 답 | 신뢰도 ≥ t | 그 밖 |
   |---|---|---|
   | 숫자열, 범위 안 | 그 값으로 자동 적재 | 값 있음 + 검수 대기 |
   | 숫자열, 범위 밖(`[haul] trips_max`) | 검수 대기 | 검수 대기 |
   | 빈 칸 | **값 없음으로 자동 적재** (`has_value_raw` 0) | 값 있음 + 검수 대기 |
   | 거절 | 검수 대기 | 검수 대기 |

   인식기는 값을 만들어 내지 않는다 — 잉크 판정이 "값 없음"인 칸은 인식기에 가지 않는다. 답의 종류를 말하지 않는 백엔드(`null`, `oracle`)는 예전 규칙이다.
   검수가 이기고 기계 값은 남는다 (ADR 0008). 기계가 정한 상태는 `doc_field.status_raw` 에 따로 남겨, 검수가 들어간 DB 에서도 기계의 판단을 잰다.
4. **기준 t 는 검증 날짜에서 고른다**: 자동 적재 오류율(자동 적재된 칸 중 정답과 다른 비율)이 목표(기본 1 %) 이하인 가장 낮은 임계값.
   비율에는 분자·분모와 윌슨 95 % 구간을 같이 낸다. 만족하는 임계값이 없으면 "자동 적재 없음". 검증은 train 날짜 안에서 날짜 단위로 떼고
   (소금값 = `split_salt` + `":val"`), test 는 마지막에 한 번만 본다 — 학습 명령은 test 줄이 있으면 거절한다.
   우선순위: 설정 `[recognize.digits] auto_accept_conf` > `site.toml` > 모델 카드 > `[pipeline] auto_accept_conf`.

## 이유

- 빈 칸을 답으로 두면 잉크 판정의 오류(값 유무의 거짓 양성)를 인식기가 바로잡는다. 합성 낮은 칸 양식에서 X 표·넘어온 글씨 칸이 전부 값 없음으로
  자동 적재되었고, 값 유무 정밀도가 `null` 보다 높아졌다(재현율은 같음).
- 거절을 따로 두면 "못 읽겠다"가 "빈 칸"이나 엉뚱한 숫자로 새지 않는다. 거절은 신뢰도와 상관없이 사람에게 간다.
- 범위는 현장의 것이라 사이트 팩에 둔다 (코드에 숫자를 적지 않는다).
- 기준은 운용에서 쓸 경로(OpenCV)로 검증 날짜에서 잰다. test 로 기준을 고르면 test 의 수치가 낙관적이 된다.

## 대가

- 진짜 값을 빈 칸으로 지워 버리는 오류가 생길 수 있다 — 자동 적재 오류로 센다. 목표 1 % 는 과제 책임자가 바꿀 수 있다.
- 검증 칸이 수백 개면 오류 한두 개로 기준이 흔들린다. 가장 낮은 임계값을 고르는 규칙은 점추정을 따르므로 구간의 위쪽이 목표를 넘을 수 있다
  (합성 시험용 모델에서 오류율 0.8 %, 구간 위쪽 1.6 % 의 예가 있었다). 표를 보고 사람이 `auto_accept_conf` 로 올릴 수 있다.
