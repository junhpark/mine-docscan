# 부록 — 명령 목록

`minedocscan <명령> [하위 명령] [선택]`. 이 쪽은 `scripts/cli_reference.py` 가 프로그램의 명령 정의에서 만든다 — 손으로 고치지 않는다
(시험이 지금의 명령과 같은지 본다). 쓰임새와 순서는 설명서의 각 장에, 규칙은 `docs/` 의 문서에.

여러 명령이 같이 받는 선택 (`[공통]`): `--config`(설정 파일), `--site`(사이트 팩), `--archive-root`(보관 폴더), `--work-root`(작업 폴더),
`--db-url`, `--json`(요약을 JSON 으로).

### `recognizer train`

크롭 + 합성 셀로 학습 → &lt;site>/models/&lt;이름>/ (torch 필요: .[train]) `[공통]`

| 인자·선택 | 뜻 | 기본값 | 고를 수 있는 값 |
|---|---|---|---|
| `--crops` | review export-crops 로 내보낸 폴더 (test 줄이 있으면 거절). 없으면 합성 셀만으로 |  |  |
| `--name` | 모델 이름 (영문·숫자·.-_). 같은 이름이 있으면 멈춘다 |  |  |
| `--synthetic` | 합성 셀 수 (기본: 실제 셀이 있으면 4000, 없으면 8000) |  |  |
| `--seed` |  | 0 |  |
| `--val-share` | 검증으로 떼는 train 날짜의 비율 (기본 0.2) | 0.2 |  |
| `--target-auto-error` | 자동 적재 오류율의 목표 (검증 날짜, 기본: 숫자 칸 0.01, 메타 필드 0.02). 이 이하인 가장 낮은 임계값을 고른다 |  |  |
| `--min-val-auto` | 기준을 정하려면 그 임계값에서 자동 적재된 검증 칸이 이만큼은 있어야 한다 (기본 100). 모자라면 자동 적재 없음 | 100 |  |
| `--steps` | 학습 스텝 (배치 64, 기본 2500 — CPU 4코어에서 약 1분 반. 분류기(choice)는 기본 600) |  |  |
| `--synthetic-geometry` `WxH[,WxH…]` | 합성 칸 크기(템플릿 px, doc_field bbox). 실제 셀이 없을 때만 쓴다 (있으면 실제 칸 크기). 기본 92x21 |  |  |
| `--out` | 모델 폴더를 직접 지정 (기본: &lt;site>/models/&lt;이름>) |  |  |
| `--allow-in-repo` | git 작업 트리 안에도 쓴다 (합성 셀만으로 만든 시험용 모델) |  |  |
| `--meta-key` `KEY[,KEY…]` | 표 밖 메타 필드의 모델: vehicle_no, operator, date.month, date.day … (export-crops --meta 의 폴더). 쉼표로 여럿 — 숫자 모델만 |  |  |
| `--reader` | --meta-key: 읽는 법. 기본은 정답이 전부 숫자열이면 digits(읽고 목록에서 고른다), 아니면 choice(분류기) |  | `digits`, `choice` |
| `--cv` `K` | --meta-key: train 날짜를 K 묶음으로 나눠 돌려 가며 읽은 것 전체로 온도·기준을 정한다 (정답이 적을 때) |  |  |
| `--min-examples` | --reader choice: 종류가 되려면 필요한 예의 수 (기본 3) | 3 |  |
| `--extra-digits` `DIR` | --meta-key (숫자 모델): 숫자 칸(운반 횟수)을 export-crops 로 내보낸 폴더 — 그 칸의 숫자를 학습에만 더한다 (후보·기준에는 쓰지 않는다. test 줄이 있거나 규격이 다르면 거절) |  |  |
| `--synthetic-meta` `DAYS` | --meta-key, --crops 없이: 합성 메타 필드 DAYS 일치로 학습 (시험용 모델, tools/synth_meta) |  |  |
