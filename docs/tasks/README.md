# 작업 지시서

Claude Code 에 맡길 작업 한 덩어리를 한 파일로 적는다. 로드맵(무엇을 언제)과 결정 기록(왜)이 있고,
지시서는 그 사이 — **이번에 무엇을 어디까지, 어떻게 확인하는가** — 를 적는다.

쓰는 법: Claude Code 에서 "`CLAUDE.md` 와 `docs/tasks/NNNN-….md` 를 읽고 단계 1부터 진행해" 라고 시작한다.

한 지시서에 들어가는 것
- 왜 만드는지, 끝났을 때 무엇이 되는지
- 이번에 하는 것과 하지 않는 것
- 이미 정한 설계 (바꾸려면 먼저 묻는다)
- 단계와 단계별 수용 기준 — 가능하면 합성 데이터로 돌릴 수 있는 테스트로
- 열린 질문과 기본값, 고칠 문서, 끝나고 보고할 것

| 번호 | 제목 | 상태 |
|---|---|---|
| [0001](0001-review-tool.md) | 최소 검수 도구 | 단계 1–5 완료 (PR #1). 단계 6 은 0002 로 옮김 |
| [0002](0002-full-archive-and-evalset.md) | 전체 묶음으로 정답 만들기 — 페이지 필드 검수, 전체 묶음 운용, 양식의 판, 원본 해상도 크롭, 평가셋 고정 | 단계 1–6 완료 (PR #3). 단계 7 선택, 8절은 사람의 일 |
| [0003](0003-digit-recognizer.md) | 숫자 인식기(운반 횟수) — 크롭 규격 통일, 학습 명령과 모델 카드, 추론 백엔드 `digits`, 자동 적재 규칙, 크롭 단위 평가. 0002 의 손질 포함 | 단계 1–6 완료 (PR #5). 8절은 사람의 일 |
| [0004](0004-page-fields-and-checks.md) | 표 밖 필드 읽기와 ✓ 판정의 정답 — 쪽 메타의 출처, 차량번호(숫자를 읽고 닫힌 목록에서 고르기)·작성자(닫힌 집합 분류), 채우기와 대조, 날짜 대조, ✓ 정답 대기열과 평가 | 단계 1–6 완료 (PR #7). 8절은 사람의 일 |
| [0005](0005-usage-logs.md) | 장비 가동 일보 — 값의 형식(소수·시각), 핸들러 `usage`(표의 역할), 가동 기록과 작업량 표, 계기의 검산(쪽 안·날짜 사이), 대기열 `readings`·`usage-check`, 템플릿 도구 | 단계 1–6 완료 (PR #9). 8절은 사람의 일 |

작업이 끝나면 상태를 "완료 (PR 번호)"로 바꾸고, 지시서와 달라진 점을 파일 끝에 적는다.
